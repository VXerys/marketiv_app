# Fitur Chat (`lib/features/chat/`)

Menangani Live Chat secara real-time yang eksklusif HANYA AKTIF saat dalam transaksi Rate Card Mode.

## Best Practices
1. **Appwrite Realtime:** Gunakan subscription Appwrite untuk menampilkan pesan masuk secara instan.
2. Custom widget seperti "Custom Offer" dikirim melalui chat untuk menyegel transaksi UMKM.
