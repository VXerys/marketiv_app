# Fitur Rate Card (`lib/features/rate_card/`)

Mode Premium/Fixed Price di mana UMKM bisa menelusuri direktori kreator, melihat paket yang ditawarkan, dan membuat pesanan.

## Best Practices
1. Kreator dibatasi maksimal memiliki 3 paket Rate Card.
2. Integrasi yang erat dengan fitur Live Chat untuk proses negosiasi sebelum dealing.
