# Shared (`lib/shared/`)

Berisi kode, komponen, utility, atau resource yang dibagikan antar berbagai fitur. Kode di sini bersifat agnostik terhadap fitur spesifik.

## Best Practices
1. Tidak boleh menyimpan logika bisnis (UseCase) dari salah satu domain.
2. Sangat berguna untuk menampung widget dasar yang direusable.
