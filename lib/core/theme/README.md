# Theme (`lib/core/theme/`)

Menangani global `ThemeData` untuk aplikasi Flutter, menggabungkan token desain (warna, tipografi) dari `core/constants/`.

## Best Practices
1. Gunakan `ThemeData` bawaan Flutter dengan Material 3.
2. Sinkronkan dengan file token yang ada di `constants/` agar warna dan font tetap konsisten (Inter & Newsreader).
